Developer Integration

Google Fonts–Style CSS API

Include a single <link> tag and start using Gujarati fonts across your HTML, React, Vue, or WordPress websites without installing anything.

Step 1 — Add to HTML <head>
<link rel="stylesheet" href="https://fontguj.pages.dev/css?family=UC_AjantaTwo">
Step 2 — Apply CSS font-family
body { font-family: 'UC_AjantaTwo', sans-serif; }
Query Multiple Families (Pipe or Comma Separated)
<link rel="stylesheet" href="https://fontguj.pages.dev/css?family=UC_AjantaTwo|AnotherFont">
